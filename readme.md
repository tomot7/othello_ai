# AIリバーシ 🎮

PyScriptを使用した、ブラウザで動作するリバーシ（オセロ）ゲームです。
Pythonで実装されたAIと対戦したり、プログラミング体験ができます。

## 特徴

*   ✅ **完全ローカル動作**: インターネット接続不要で、ブラウザ上でPythonコードが実行されます
*   ✅ **AI対戦**: 3段階の難易度（かんたん・ふつう・むずかしい）から選択可能
*   ✅ **先手・後手選択**: 黒（先手）か白（後手）を選んでプレイ可能
*   ✅ **リアルタイムUI**: 置ける場所の強調表示、最後の手のハイライト
*   ✅ **プログラミング体験機能**:
    *   **AIカスタマイズ**: AIの評価値を自分で設定してオリジナルAIを作成
    *   **UI作成体験**: HTML/CSSでゲーム画面を作るチュートリアル

## 前提条件

*   **Node.js**: ローカルサーバーを起動するために `npx` コマンドを使用します。Node.jsがインストールされている必要があります。

## 起動手順

1.  **サーバーの起動**
    フォルダ内の `start-server.bat` をダブルクリックして実行してください。
    コマンドプロンプトが立ち上がり、ローカルサーバーが起動します。
    （サーバー起動時に「パブリックネットワーク、プライベートネットワーク、ドメインネットワークにこのアプリへのアクセスを許可しますか？」と表示されたら、「キャンセル」を押す。）

2.  **ブラウザでアクセス**
    任意のWebブラウザを開き、以下のアドレスを入力してください。
    `http://localhost:8080`

3.  **ゲームの開始**
    表示されたファイル一覧から **`app/`** をクリックしてください。
    ゲーム画面が表示されます。

## 遊び方

### 基本操作

*   ゲーム開始時に**難易度**と**先手・後手**を選択できます
*   緑色の盤面上の、明るい緑色で表示された場所をクリックすると石を置けます
*   黄色で表示されるマスは、最後に石が置かれた場所です
*   パスは自動的に判定されます
*   双方が置けなくなるか、盤面が埋まるとゲーム終了です

### AIの難易度

| レベル | 名称 | 戦略 |
|--------|------|------|
| 😊 | かんたん | わざと不利な手を選ぶ |
| 🤔 | ふつう | ひっくり返す数が多い手を選ぶ |
| 😈 | むずかしい | マスの価値を評価して最善手を選ぶ |

### プログラミング体験

*   **「🤖 AIをカスタマイズ」ボタン**: AIが各マスをどれくらい重視するかを自分で設定できます。角の価値や角の隣の価値を変更して、オリジナルのAIを作成できます。

*   **「👀 AIのコードを見る」ボタン**: AIの思考ロジック（Python）を確認できます。

*   **「🎨 UI作成体験」ボタン**: HTML/CSSでリバーシのゲーム画面を作る10ステップのチュートリアルに挑戦できます。

## トラブルシューティング

### ゲームが表示されない場合
*   ブラウザの開発者ツール（F12）でエラーを確認してください
*   サーバーが起動しているか確認してください
*   `http://localhost:8080`（`file://`ではなく）でアクセスしてください

### サーバーが起動しない場合
*   ポート8080が他のアプリで使用されていないか確認してください
*   Node.jsがインストールされているか確認してください
